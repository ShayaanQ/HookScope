# Milestone 1 — Acceptance Checklist

Every row is objective and has one status: `PENDING`, `FAIL`, or `PASS`.

Only a human reviewer may change a row to `PASS`. Codex reports evidence and proposes
status changes; it must not edit a criterion to weaken the requirement or mark itself
complete.
